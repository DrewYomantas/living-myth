# Visual references — concept references ONLY

Everything in this folder is **art-direction reference material, not game content**:

- **Not in-game assets.** Nothing here ships, gets imported into `godot/`, or is used as
  a texture/sprite/source image — unless Drew explicitly asks later.
- **Not production art.** The `gpt-northstar-*.png` images are AI-generated concept
  mockups (Batch 1 "Style Lock / North Star" per `DESIGN.md`); the rest are screenshots
  of other games (Metropolis 1998, Parkitect, RimWorld) used as influence references.
- **They depict unbuilt and unmodeled things on purpose** (resources, settlement
  populations, named buildings, Bless/Plague/Terrain tools, a named world). The sim does
  not model these yet; the viewer must not fake them. `docs/VISUAL_STYLE.md` is the
  binding interpretation of what is honest, aspirational, or forbidden.
