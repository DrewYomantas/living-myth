# Feel-Test Checklist

Per-system live watch-log sign-off before a beta/release. Run `tools/build/feeltest.ps1`
to capture evidence shots under `dist/feeltest/<system>/`, then F5 the viewer and watch each
system unfold. Mark each row, note the year you saw it, and sign off. A row only passes if the
behaviour is **visible in the live viewer**, not merely green in its gate.
